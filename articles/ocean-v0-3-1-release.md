# Ocean v0.3.1 — Signed Maintenance Release

**A refreshed, signed macOS package with verified notarization and updated bundled-sidecar integrity data.**

---

Ocean v0.3.1 is a maintenance release. It does not change the in-app experience from v0.3.0.

## What changed

- The macOS application package was rebuilt, signed, notarized, and stapled for macOS Gatekeeper verification.
- The bundled Mastra sidecar manifest was refreshed with the integrity hash for the packaged release asset.
- The update package and its signature were published for Apple Silicon Macs.
